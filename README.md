# Mechanically_Passive_3D_Printable_Haptic_Feedback
Haptic feedback has become an important function for prosthetics, but most devices on the market are limited by high costs and battery power. This study aimed to create a device that provides force feedback in a non-battery-powered way. This was achieved using a mechanically passive system. The modules connect to a Bowden tube, and metal string was inserted through the system to provide tension and feedback.
